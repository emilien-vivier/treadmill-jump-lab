Engineering report

Steady-state calculations for the current design. The live simulation above uses the same equations, plus stick-slip, inertia and the Arduino's timing.

Motor torque–speed vs load

Motor, full commandLoad at the motor shaftRated torque

  • Gear ratio i = gearbox × Z2/Z1 × Z4/Z3 · η = ηgb × ηbevel²
  • Belt speed v = ωmotor / i × D/2
  • Motor torque Tm = F × R / (i × η)
  • DC motor I = (u·V − Kt·ω)/R, T = Kt·(I − I₀)
  • Induction (Kloss) T = 2Tb / (s/sb + sb/s), s = (ωs − ω)/ωs, ωs = 2πf/p
  • Capstan grip Fmax = 2T₀·tanh(μθ/2) per roller
  • Deck friction F = μ·(mbelt/2 + mload)·g
  • Hinge loss F = n·2·h·½k·(p/R)² / p
  • Chordal ripple Δv/v = 1 − cos(π·p / 2πR)
  • Reflected inertia meq = Jrotor·i² / R²
  • Rack y = m·Z/2 × Δφ(α) · Tservo = dy/dα × (m·g + m·ÿ + Fguide)
  • Pivot detect if μ·mobs·g·L > Tpre + k·θthr · ADC = 1023·θ/θpot

AC: RC filter (10 kΩ + 10 µF) → LM358 ×2 gain on 12 V → VFD analog input 0–10 V.

D8DC: BTS7960 R_EN + L_EN.
AC: optocoupler → VFD FWD/RUN terminal.
D4Jump / start button to GND.
D9Servo signal. Servo + and − on a separate 5–6 V supply, GND shared.
A0Pivot potentiometer wiper (10 kΩ linear), ends on 5 V and GND.
D7Pivot microswitch to GND, if USE_POT = 0.
D13Game-over LED.

Mains wiring to a VFD (230 V) must be done by someone qualified. The Arduino only touches the VFD's low-voltage control terminals. Put a hardware emergency stop in the motor power line: the sketch's collision stop is not a safety function.

The Servo library uses Timer1, so D9/D10 lose analogWrite. The sketch moves Timer2 to 3.9 kHz for the motor PWM on D3, so don't use tone().
